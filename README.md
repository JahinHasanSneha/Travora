# Travora

Travora is a travel booking platform that allows users to explore and book hotels, packages, cruises, and trips. It provides features such as user authentication, reviews, and profile management.

## Features
- **User Authentication**: Secure login and registration for users.
- **Profile Management**: Users can update their profile details.
- **Hotel and Package Listings**: Explore hotels, packages, and other travel options.
- **Review System**: Users can leave reviews for hotels, packages, and trips.
- **Dynamic Ratings**: Average ratings are updated dynamically using database triggers.
- **Admin Features**: Admins can manage users and listings.
